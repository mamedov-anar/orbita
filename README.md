# ОРБИТА

Интерактивная Солнечная система с восемью планетами, просмотром Земли и Луны, выбором даты, масштабом и ускорением времени.

Отдельная статическая версия для GitHub Pages. Все расчёты и анимация работают в браузере. База данных, сервер и ключи доступа не требуются.

## Сайт

https://mamedov-anar.github.io/orbita/

## Локальная работа

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run build:pages
npm test
npm run preview
```

Локальная версия открывается на http://localhost:4173/orbita/.

## Публикация

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch → main → /docs**. Папка `docs/` содержит проверенную готовую сборку; `.nojekyll` сохраняет доступ к файлам `_next/`.

После изменения исходников выполните `npm run build:pages` и `npm test`, затем сохраните исходники и обновлённую папку `docs/` в GitHub. GitHub Pages опубликует изменения автоматически.

Для другого имени репозитория задайте `PAGES_BASE_PATH=/имя-репозитория` при сборке, тестировании и локальном просмотре. Для другого аккаунта также задайте `PAGES_ORIGIN=https://имя-аккаунта.github.io` при сборке.

## Управление

- Выбор планеты — кнопки внизу или клавиши 1–8, когда карта в фокусе.
- Enter — приближение, Escape — возврат ко всей системе.
- Стрелки — ракурс, плюс и минус — масштаб.
- Дата и время задаются в UTC.

Расстояния отображаются в сжатом масштабе. Модель предназначена для исследования и иллюстрации, а не для навигации.
